# Marca d'água em PNG (opcional)

Pra adicionar uma logo/marca em PNG às fotos (além da marca de texto que já
existe), suba um arquivo PNG com fundo transparente **exatamente com este nome**
nesta pasta:

```
backend/src/assets/marca-dagua.png
```

Recomendado: fundo transparente, proporção quadrada ou próxima disso,
resolução de uns 500x500px já é suficiente (ela é redimensionada
automaticamente pro tamanho de cada foto).

Se esse arquivo não existir, nada quebra — o site continua usando só a
marca de texto normalmente, sem erro nenhum.
